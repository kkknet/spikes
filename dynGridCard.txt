Here’s how you can create a custom React component using TypeScript to dynamically render multiple Syncfusion cards in a grid layout, based on the provided JSON data.

Step 1: Install Required Packages

Install Syncfusion packages for React cards and grid layout:

npm install @syncfusion/ej2-react-cards @syncfusion/ej2-react-layouts

Step 2: Create the Component

Create a new TypeScript file, e.g., DynamicCardGrid.tsx.

import React from "react";
import { CardComponent } from "@syncfusion/ej2-react-cards";
import { GridLayout } from "@syncfusion/ej2-react-layouts";
import "./DynamicCardGrid.css";

// Define the TypeScript interface for the data
interface CardData {
  type: string;
  score: number;
}

interface DynamicCardGridProps {
  data: CardData[];
}

const DynamicCardGrid: React.FC<DynamicCardGridProps> = ({ data }) => {
  return (
    <GridLayout className="grid-layout" columns={3} cellSpacing={[10, 10]}>
      {data.map((item, index) => (
        <div key={index} className="card-container">
          <CardComponent className="index-score-card">
            <div className="index-score-title">{item.type}</div>
            <div className="index-score-value">{item.score}</div>
          </CardComponent>
        </div>
      ))}
    </GridLayout>
  );
};

export default DynamicCardGrid;

Step 3: Create the CSS File for Styling

Create a CSS file named DynamicCardGrid.css to style the cards and grid layout.

.grid-layout {
  margin: 20px;
  padding: 10px;
  background-color: #f9f9f9;
}

.card-container {
  display: flex;
  justify-content: center;
  align-items: center;
  padding: 10px;
}

.index-score-card {
  width: 150px;

.index-score-value {
  font-size: 36px;
  color: #d32f2f; /* Red color */
  font-weight: bold;
}

Step 4: Use the Component in Your App

Now, you can use the DynamicCardGrid component in your main application and pass the JSON data as props.

import React from "react";
import DynamicCardGrid from "./DynamicCardGrid";

const cardData = [
  { type: "ABC", score: 5 },
  { type: "XYZ", score: 15 },
  { type: "PQR", score: 25 },
];

const App: React.FC = () => {
  return (
    <div className="App">
      <h1>Dynamic Card Grid</h1>
      <DynamicCardGrid data={cardData} />
    </div>
  );
};

export default App;

Explanation

	1.	GridLayout from Syncfusion:
	•	We use the GridLayout component to arrange the cards dynamically in a grid layout. You can adjust the columns and cellSpacing properties as needed.
	2.	Dynamic Rendering:
	•	The data array is mapped to render a card for each item dynamically.
	3.	TypeScript Interfaces:
	•	The CardData interface defines the structure of the data items to ensure type safety.
	•	The DynamicCardGridProps interface ensures that the component receives data of the correct type.
	4.	Styling:
	•	Custom styles in DynamicCardGrid.css ensure the cards and grid layout match the desired look.
	5.	JSON Data Example:
	•	You can pass any array of objects in the shape of [{ type: string, score: number }] to the component.

This implementation is dynamic and allows you to easily modify the data or grid configuration as needed. Let me know if you need further enhancements!
