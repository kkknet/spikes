#### **2. Modify the Query to Include Both Entities**

First, adjust your query to join `ExistingEntity` with `MyEntity` (which contains the JSON column):

```csharp
var flatData = context.FlatDatas.FromSqlRaw(@"
    SELECT
        e.Id,
        e.SomeProperty,
        JSON_VALUE(c.value, '$.Name') AS Name,
        JSON_VALUE(c.value, '$.Value') AS Value
    FROM 
        ExistingEntities e
    INNER JOIN 
        MyEntities t ON e.Id = t.Id
    CROSS APPLY 
        OPENJSON(t.JsonColumn, '$.FieldValues.Field') AS c
").ToList();
```

**Note:** Adjust the join condition (`ON e.Id = t.Id`) according to your actual database schema.

#### **3. Group and Combine the Data**

Now, group the data by `Id` and create dynamic objects that include both the existing properties and the dynamic properties from the JSON:

```csharp
var combinedData = flatData
    .GroupBy(f => new { f.Id, f.SomeProperty })
    .Select(g =>
    {
        dynamic obj = new ExpandoObject();
        var dict = (IDictionary<string, object>)obj;

        // Add existing entity properties
        dict["Id"] = g.Key.Id;
        dict["SomeProperty"] = g.Key.SomeProperty;

        // Add dynamic properties from JSON
        foreach (var item in g)
        {
            dict[item.Name] = item.Value;
        }

        return obj;
    })
    .ToList();
```

#### **4. Output the Results**

Finally, iterate over the `combinedData` list and output the properties:

```csharp
foreach (var item in combinedData)
{
    var dict = (IDictionary<string, object>)item;
    foreach (var kvp in dict)

    }
    Console.WriteLine();
}
```

#### **Combining Existing Properties with Dynamic Properties:**

- **Existing Entity Properties:**
  - We use `f.Id` and `f.SomeProperty` from the `ExistingEntity`.

- **Dynamic JSON Properties:**

  - Since the `Name` values are dynamic, we can't define them in a static class.

- **Grouping Data:**
  - We group by the existing entity's properties to consolidate all dynamic properties under each `Id`.

- **Creating Dynamic Objects:**
  - We use `ExpandoObject` to create an object whose properties can be set at runtime.
  - We add both the existing entity's properties and the dynamic properties into this object.

#### **Advantages of This Approach:**

- **Flexibility:**

### **Alternative Approach: Parsing JSON in C#**

If your SQL Server version doesn't support `OPENJSON`, or you prefer to parse JSON in C#, you can adjust the code accordingly.

#### **Retrieve Data from the Database**

First, retrieve both the existing entities and the JSON data:

```csharp
var data = context.ExistingEntities
    .Include(e => e.MyEntity) // Assuming a navigation property exists
    .ToList();
```

#### **Combine Data in C#**

Now, parse the JSON and combine it with the existing entity properties:

```csharp
var combinedData = data.Select(e =>
{
    dynamic obj = new ExpandoObject();
    var dict = (IDictionary<string, object>)obj;

    // Add existing entity properties
    dict["Id"] = e.Id;
    dict["SomeProperty"] = e.SomeProperty;

    // Parse JSON data
    using (JsonDocument doc = JsonDocument.Parse(e.MyEntity.JsonColumn))
    {
        var fields = doc.RootElement.GetProperty("FieldValues").GetProperty("Field");
        foreach (var field in fields.EnumerateArray())
        {
            var name = field.GetProperty("Name").GetString();
            var value = field.GetProperty("Value").GetString();
            dict[name] = value;
        }
    }

    return obj;
}).ToList();
```

#### **Output the Results**

```csharp
foreach (var item in combinedData)
{
    var dict = (IDictionary<string, object>)item;
    foreach (var kvp in dict)
    {
        Console.Write($"{kvp.Key}: {kvp.Value}, ");
    }
    Console.WriteLine();
}
```

### **Considerations:**

- **Error Handling:**
  - Ensure you handle exceptions that may occur during JSON parsing.
  - Check for null values and missing properties.

- **Performance:**
  - Parsing JSON in C# can be less efficient for large datasets compared to SQL Server's `OPENJSON`.
  - If performance is critical, consider using stored procedures or server-side processing.

- **Type Safety:**
  - Using dynamic objects means losing compile-time type checking.
  - Be cautious when accessing properties to avoid runtime errors.

- **Serialization:**
  - If you need to serialize the combined data to JSON or another format, dynamic objects can be easily serialized using `System.Text.Json` or `Newtonsoft.Json`.
