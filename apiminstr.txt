Below are step-by-step instructions to perform common tasks in Azure API Management (APIM), including adding an API, creating an operation, adding a schema, backend, subscription, and policy fragment:

1. Adding an API to Azure APIM
	1.	Sign in to Azure Portal: Go to the Azure Portal.
	2.	Navigate to APIM Instance:
	•	Select your API Management service instance.
	3.	Create a New API:
	•	In the left-hand menu, select APIs under API Management.
	•	Click on + Add API.
	•	Choose the type of API (e.g., HTTP, OpenAPI, SOAP, or GraphQL).
	4.	Configure API Details:
	•	Enter a Display name (e.g., “My API”).
	•	Provide a Name (unique identifier for the API).
	•	Enter the Web Service URL (backend URL for the API).
	•	Specify the API URL suffix (e.g., /myapi).
	•	Choose a Product to associate the API with.
	5.	Save the API:
	•	Click Create or Save.

2. Adding an Operation to an API
	1.	Select Your API:
	•	In the APIM instance, go to APIs and select the desired API.
	2.	Add an Operation:
	•	Click + Add Operation.
	3.	Configure the Operation:
	•	Enter a Display Name (e.g., “Get Item”).
	•	Define the Name (unique operation identifier).
	•	Set the URL template (e.g., /items/{id}).
	•	Choose an HTTP method (e.g., GET, POST).
	•	Optionally, add Query Parameters or Request Body.
	4.	Save the Operation:
	•	Click Save.

3. Adding a New Schema
	1.	Navigate to Schemas:
	•	In the APIM instance, click Schemas under APIs.
	2.	Create a New Schema:
	•	Click + Add Schema.
	3.	Configure the Schema:
	•	Provide a Name for the schema.
	•	Select the Content Type (e.g., JSON or XML).
	•	Define the schema structure (e.g., JSON Schema definition).
	4.	Save the Schema:
	•	Click Save.

4. Adding a New Backend
	1.	Navigate to Backends:
	•	In the APIM instance, select Backends under APIs.
	2.	Create a New Backend:
	•	Click + Add Backend.
	3.	Configure Backend Details:
	•	Provide a Name for the backend.
	•	Select the Backend Type (e.g., HTTP, Function App, Logic App).
	•	Enter the Backend URL.
	•	Optionally, configure authentication or other settings.
	4.	Save the Backend:
	•	Click Save.

5. Adding a New Subscription
	1.	Navigate to Subscriptions:
	•	In the APIM instance, select Subscriptions under APIs.
	2.	Create a New Subscription:
	•	Click + Add Subscription.
	3.	Configure Subscription Details:
	•	Enter a Name for the subscription.
	•	Select the associated Product.
	•	Choose the User (or leave it unassigned for shared use).
	•	Set the State (e.g., active).
	4.	Save the Subscription:
	•	Click Save.

6. Adding a New Policy Fragment
	1.	Navigate to Policy Fragments:
	•	In the APIM instance, select Policy Fragments under Policies.
	2.	Create a New Fragment:
	•	Click + Add Fragment.
	3.	Define the Fragment:
	•	Provide a Name for the fragment.
	•	Enter the XML-based Policy Code (e.g., <set-header> or <rate-limit> policies).
	4.	Save the Policy Fragment:
	•	Click Save.

Additional Notes:
	•	Policies can be applied at different levels (e.g., API, Operation, Product, or Global).
	•	Test your API operations using the Developer Portal or the Test tab in the APIM instance.
	•	Manage access to your APIs through products, groups, and subscriptions.
